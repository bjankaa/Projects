# Software Projects

## Projects

Full-stack multiplayer card game with a Go backend and Vue.js frontend.

Key features:
- REST APIs
- JWT-based authentication
- Real-time communication using WebSockets
- PostgreSQL database
- Core game logic
- Dockerized development environment
