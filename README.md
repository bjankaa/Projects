# Software Projects

A collection of software development projects covering Java, backend, full-stack, and machine learning.

## Projects

### Online Multiplayer Card Game - ULTI

**Go · Vue.js · PostgreSQL · Docker**

A full-stack online multiplayer card game based on a simplified version of the traditional Hungarian card game Ulti.

The application includes a Go backend, Vue.js frontend, real-time multiplayer communication, authentication, relational database support, and a containerized architecture.

[View project](./multiplayer-card-game)

-------------------------------------------------------------------------

### Renju Board Game

**Java**

A desktop implementation of the Renju strategy board game developed using object-oriented design.

The application includes game logic, move and rule validation, pattern-based win detection, a graphical user interface, score tracking, and persistent game results.

[View project](./renju-java)

-------------------------------------------------------------------------

### AlexNet Image Classification

**Python · Keras · CIFAR-10**

An image classification project exploring the AlexNet convolutional
neural network architecture using the CIFAR-10 dataset.

The project includes model adaptation, training, data augmentation,
optimizer comparison, and confusion matrix evaluation.

[View project](./alexnet-image-classification)

-------------------------------------------------------------------------

### Synthetic Image Classification

**Python · TensorFlow · Keras · OpenAI API**

An experimental machine learning project investigating whether
AI-generated images can be used as training data for an image
classification model.

A synthetic dataset was generated across the CIFAR-10 categories and
used to train an AlexNet-based convolutional neural network.

The project evaluates how well the model generalizes to real CIFAR-10
images and compares Adam and Nadam optimization.

[View project](./synthetic-image-classification)
